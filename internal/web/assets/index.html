Le groupe à déclarer

Adopter ces dépôts, c'est les réunir sous un groupe qui saura les lire avec ce gabarit. Sur GitHub, rien n'est créé, renommé ni supprimé : le groupe est une fiche gardée sur cette machine, et l'oublier ne touche aucun dépôt.

Ce que le gabarit a lu à la place de {student}

Rien n'est définitif : la liste s'importe ou se corrige plus tard. Le gabarit, lui, sert tant que les dépôts gardent ces noms — « Réglages du groupe » propose ensuite de les renommer vers la nomenclature courante.
