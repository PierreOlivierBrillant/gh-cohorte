# Travail de session

Ce dépôt a été créé pour vous. Il contient le squelette du travail à remettre.

## Marche à suivre

1. Clonez ce dépôt : `git clone <adresse du dépôt>`
2. Complétez `src/main.py`
3. Envoyez votre travail : `git add . && git commit -m "Mon travail" && git push`

Vos envois restent visibles de vous seul et de l'équipe enseignante.
